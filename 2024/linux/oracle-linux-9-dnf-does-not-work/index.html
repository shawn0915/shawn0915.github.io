Description

尝试安装 cmake 时，遇到以下错误。

原因：在某些特定网站上使用 curl 时，不会返回任何输出，而是显示错误消息。当远程端意外关闭 TLS 连接（即未正确关闭）时，Oracle Linux 9 自带的 curl 会失败。
