什么是 VMware Workstation？

VMware Workstation Pro 是 VMware Workstation 的专业版，它提供了更高级的功能和改进的性能，主要面向企业用户、开发人员和IT专业人士，主要用于软件开发、测试、系统演示和教育等领域。

VMware Workstation Pro 是一款优秀的虚拟化软件，它允许用户在单一的物理机器上运行多个操作系统。这款软件模拟了完整的计算机环境，包括硬件组件如CPU、内存、硬盘和网络适配器等，使得用户能够在虚拟机中安装和运行不同的操作系统，而无需重启物理机器。

下载 VMware Workstation Pro

VMware 软件下载链接已经合并到博通网站，原有网站已停用。

注册并登录博通网站，即可下载软件，下载链接[1]

这里可以看到，VMware Workstation Pro for Windows 安装包【VMware-workstation-full-17.5.2-23775571.exe】大小为 618.26 MB 于5月10日更新。

安装 VMware Workstation Pro

安装包下载完成后，双击安装。这里可以看到，版权协议已经变更为 Broadcom。

下一步，接受条款。

点击下一步，开始安装。

完成安装，会在桌面创建快捷图标。

双击运行，这里选择个人用途，无需再填写注册码。

从此告别绿色版、注册机、病毒软件。

点击继续，弹出欢迎使用页面。

点击【帮助->关于】，查看产品信息。可以看到【仅限于个人用途】，没有过期限制。

真棒！

点击【创建新的虚拟机】，选择【Linux】，可以看到 Workstation 17.5 已经支持 RHEL 9/Oracle Linux 9/Rocky Linux, Suse 15等操作系统的最新版本。

以及支持Linux 6.x, 5.x 最新版本内核。

到此，Workstation 已经安装完成，可以开启全新虚拟机之旅！
