[译] 甲骨文发布Oracle数据库对MongoDB的接口

2022-03-18 499 words 1 min read views

原文地址：https://www.dbta.com/Editorial/News-Flashes/Oracle-Announces-Oracle-Database-API-for-MongoDB-151394.aspx
原文作者：Joyce Wells

甲骨文发布了一个新的正式版接口，用于自治JSON数据库——Oracle数据库对MongoDB的接口。甲骨文首席产品经理 Roger Ford 在甲骨文数据库内部 博客 中宣布了这一消息。

Oracle 表示，对于这个新的API，开发者可以继续使用MongoDB的开源工具和驱动连接到Oracle自治JSON数据库，同时可以使用Oracle的多模功能和自动驾驶数据库的优势。客户现在可以在Oracle云基础设施(OCI)上运行MongoDB，而且该公司表示，一般情况下，既存的应用程序不需要或只需要做很小的调整，只需修改连接字符串。

“自治JSON数据库是以JSON为中心的低成本开发而设计的。开发者可以同时使用MongoDB接口和Oracle SQL的来访问同一个文档数据，以避免需要转移数据到单独的数据库，来进行分析、机器学习、空间分析等。”，Ford如是说。

据Ford所言，这提供了MongoDB Atlas的替代方案，并有如下高级特性：

  • 使用可伸缩的SQL来做完整的分析查询和报告
  • 关联不同的JSON文档集或关联JSON文档和其他关系型数据
  • 关系型数据和分析查询结果展示为JSON文档数据
  • 运行机器学习算法或基于JSON文档数据的空间分析
  • 使用Oracle APEX进行低代码应用程序开发
  • 无持续时间和数据大小限制的ACID事务
  • 企业安全特性，如用于纺织管理员访问用户数据的数据库审计功能（Database Vault）

针对MongoDB的API也可用于Oracle的旗舰云数据库服务——自治数据库。
更多信息，请参阅：
https://docs.oracle.com/en/database/oracle/mongodb-api/mgapi/index.html
