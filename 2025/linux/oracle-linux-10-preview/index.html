Oracle Linux 10 开发者预览版

Oracle Linux 10 开发人员预览版现已推出，包含许多新功能、安全性和错误修复。需要注意，此版本不适用于生产用途并且正在积极开发中。

正式版本计划于 2025 年中期上市。

搭载的内核

对于 x86_64 平台，Oracle Linux 10 附带以下默认内核包：

  • kernel-6.11.0-0.rc5.23.el10（Red Hat 兼容内核 (RHCK)）
  • kernel-ueknext-6.12.0-4.el10ueknext（Unbreakable Enterprise Kernel Release Next (UEK-next)）

对于新安装，UEK 内核会自动启用和安装。它还会在首次启动时成为默认内核。

对于 aarch64 平台，Oracle Linux 仅附带 UEK 内核。

下载安装包

Oracle Linux 10 的 ISO 已开放下载，可从官方网站进行下载。

https://www.oracle.com/linux/downloads/linux-beta10-downloads.html

待 Oracle Linux 10 正式发布后，你可以从代理网站下载 ISO 镜像。

  • 波兰华沙理工大学 PL, University of Warsaw - ICM

http://ftp.icm.edu.pl/pub/Linux/dist/oracle-linux/

  • Linux 内核组织 US, mirrors.kernel.org

http://mirrors.kernel.org/oracle/

软件包仓库

Oracle Linux 10 默认启用三个软件仓库。

  • ol10_appstream: Oracle Linux 10 Application Stream 软件包的开发者预览版
  • ol10_baseos_latest: Oracle Linux 10 BaseOS 软件包的开发者预览版
  • ol10_developer_UEKnext: 用于 Oracle Linux 的 UEK-next 开发者预览版

BaseOS 存储库包含核心 RPM 软件包集，而 AppStream 存储库提供其他 RPM，包括用于应用程序和开发人员工具的 RPM。这两个存储库都是必需的，并且应该保持启用状态。

最新的 Linux

安装 Oracle Linux 10 后，默认启用 UEK 内核，其基于 Kernel 6.12.0 构建，并更新诸多关键组件，如 OpenSSH, Podman, GCC, GDB, Python 等。

Oracle Linux 10 中的 GCC 14 默认为 x86-64-v3 微架构级别。此级别默认启用某些功能，例如 AVX 和 AVX2 指令集以及融合乘加 (FMA) 指令集。

提供的数据库

Oracle Linux 10 提供如下数据库。

  • MySQL 8.4
  • MariaDB 10.11
  • PostgreSQL 16
  • Valkey 7.2

MySQL 是世界上最流行的开源数据库。全球许多规模最大、发展最快的组织（包括 Facebook、Twitter、Booking.com 和 Verizon）都依赖 MySQL 来节省时间和金钱，为其大容量网站、关键业务系统和打包软件提供支持。MySQL 8.4 于 2024 年 4 月发布，是目前最新长期支持版本。

Valkey 是一款高性能数据结构服务器，主要服务于键/值工作负载，可用于缓存、消息队列。它支持各种原生结构和可扩展的插件系统，用于添加新的数据结构和访问模式。Valkey 是 Redis 7.2.4 版本的开源分支。Valkey 与 Redis OSS 7.2 和所有早期开源 Redis 版本兼容。Redis 社区版 (CE) 7.4 及更高版本不是开源的，数据文件与 Valkey 不兼容。你可以通过迁移工具将 Redis 服务器中的数据迁移到 Valkey 数据库。
